# jQuery Sortable

These files are vendored from `es-jquery-sortable` 0.9.13-patch2:
https://registry.npmjs.org/es-jquery-sortable/-/es-jquery-sortable-0.9.13-patch2.tgz

The package's Composer/npm dependency metadata requires jQuery 2, although
the plugin uses APIs available in jQuery 3. Vendoring preserves the existing
touch handling and scrolling fixes without overriding dependency constraints
or switching to a fork that lacks those fixes. Only line endings and trailing whitespace are normalized.

The BSD license is included in both JavaScript files. Keep the source and
minified files together when updating this plugin.
